# Ethan Bailey

I'm a developer based in New York, building lots of things related to music technology, automation and optimization. I develop audio QA tools for a work, and for fun I create services for my homelab, design workflow tools for musicians, build full-stack web apps and pad-hack old music gear.

Check out my blog at [ebai.dev](https://ebai.dev), or my music at [tarnisher.cc](https://tarnisher.cc).

## Some projects

- [barback](https://github.com/ebai101/barback) - audio validation and repair tool for sample packs
- [aiodbx](https://github.com/ebai101/aiodbx) - asyncio Python implementation of the Dropbox HTTP API
- [xc-bela-container](https://github.com/ebai101/xc-bela-container) - Dockerized cross-compilation for the Bela platform
- [Reason.spoon](https://github.com/ebai101/Reason.spoon) - Hammerspoon automation layer for Reason on macOS
